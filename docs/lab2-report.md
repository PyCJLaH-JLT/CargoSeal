# Звіт CargoSeal

ЛР2 виконана для Літвінова Руслана Олексійовича, ІО-36. Звіт PDF знаходиться у папці студента Lab02/Reports. ЛР1 збережена без змін. Усі шість напрямів методички виконав один учасник.

Матеріали відтворення в цьому репозиторії: docs/captures з повними VCD.gz, .sr, анотаціями, manifest та вимірюваннями; docs/figures з Graphviz sources і PDF/PNG; docs/verification/lab2 з build/tests/coverage/CI logs. docs/screenshots містить справжні знімки Wokwi та PulseView. Формули, пороги та точні команди наведено в PRD і uart-protocol.

Файли результату:

Збережені VCD і .sr є записами попереднього запуску, їх не називають live acquisition.
