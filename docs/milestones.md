# План CargoSeal

Власник: Літвінов Руслан Олексійович, ІО-36.

## ЛР1

1. Зберегти HAL-шаблон Nucleo-C031C6, CubeMX `.ioc`, Dockerfile та схему з UART.
2. Описати режими контейнера, вимоги й критерії перевірки, дослідити компоненти GPIO/I²C/ADC.
3. Виконати дві чисті Docker-збірки на Mac, порівняти SHA256 ELF/HEX/BIN, окремо зібрати на Ubuntu 24.04. Зберегти фактичні логи та версії інструментів.
4. Запустити Wokwi за доступної ліцензії, показати ready, tick і LED. Зберегти реальні докази запуску. Симуляція ще не підтверджена.
5. Окремо підготувати PDF-звіт зі скриншотами. Цих матеріалів у поточній роботі ще немає.

## ЛР2

1. Перевірити майбутні піни у CubeMX та ST datasheet; додати PIR, MPU6050 й LDR до схеми. Узгодити I²C timing та ADC, зберегти user code при генерації.
2. Окремо перевірити GPIO-фронти, ідентифікацію й читання MPU6050, діапазон ADC та напрям зміни світла.
3. Замінити секундний цикл на опитування за `HAL_GetTick`, з обмеженими тайм-аутами. DMA не планується через обмеження моделі Wokwi.
4. Додати явне керування режимами, формат журналу та правила повторів подій із PRD. Зміна режиму не повинна приховувати вже зафіксовану тривогу.
5. Провести T02..T12, окремо межі порогів, переходи, NACK, одночасні сигнали та навантаження UART. За результатами уточнити початкові пороги й частоти.

Критерій готовності ЛР2: тести мають фактичні результати й часові вимірювання, а не лише перелік очікувань. Фізичну пломбу, точну оцінку пошкодження та енергонезалежний журнал прототип не реалізує.
